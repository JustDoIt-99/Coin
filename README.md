## 📌 주문/체결 흐름

### 시장가 매수 주문

시장가 매수는 Upbit **매도 호가를 순차적으로 소진하며 체결 수량과 체결 금액을 계산한 뒤, 이를 사용자 자산과 거래 내역에 반영**합니다.  

<img width="520" height="736" alt="image" src="https://github.com/user-attachments/assets/2c2be1a4-ee52-42af-9077-5a382df998e2" />

[1] 시장가 매수 주문이 들어오면 먼저 **사용자의 KRW 자산 잔고를 확인**합니다.  
[2] Upbit Orderbook의 매도 호가를 순차적으로 반영해 실제 체결량과 총 체결 금액을 계산하고, 이를 바탕으로 평균 체결가를 산출합니다.  
[3] 이후 트랜잭션 내부에서 KRW 자산을 행 잠금(Lock)으로 다시 조회해 실제 체결 금액만큼 차감하고, 전체 체결 수량을 반영하여 평균 매수가를 갱신합니다.  
[4] 체결 결과는 거래 내역과 자산 변동 이력에 함께 저장됩니다.  
[5] 마지막으로 자산 갱신 이벤트로 체결 이벤트를 각각 발행해 클라이언트에 변경 사항을 전파합니다.  


### 시장가 매도 주문

시장가 매도는 Upbit **매수 호가를 순차적으로 소진하며 체결 수량과 체결 금액을 계산한 뒤, 이를 사용자 자산과 거래 내역에 반영**합니다.  

<img width="522" height="729" alt="image" src="https://github.com/user-attachments/assets/08cbe80a-be79-475b-9754-ac14dd6f9271" />

[1] 시장가 매도 주문이 들어오면 먼저 **사용자의 코인 자산 보유 수량을 확인**합니다.  
[2] Upbit Orderbook의 매수 호가를 순차적으로 반영해 실제 체결 수량과 총 체결 금액을 계산하고, 이를 바탕으로 평균 체결가를 산출합니다.  
[3] 이후 트랜잭션 내부에서 코인 자산과 KRW 자산을 행 잠금(Lock)으로 다시 조회한 뒤, 코인 자산에서는 전체 체결 수량만큼 차감하고 kRW 자산에는 실제 체결 금액만큼 반영합니다.  
[4] 체결 결과는 거래 내역과 자산 변동 이력에 함께 저장됩니다.
[5] 마지막으로 자산 갱신 이벤트와 체결 이벤트를 각각 발행해 클라이언트에 변경 사항을 전파합니다.
